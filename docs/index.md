# Welcome to the CommonRoad Dataset Converter

This tool allows users to convert a number of [datasets](./datasets.md) to the CommonRoad format with a variety of options.
We support all levelX datasets (e.g., highD, exiD, rounD) as well as our own Munich dataset MONA and many more.

**Prominent use cases include**:

- real-world datasets for learning-based motion planning and prediction, e.g., using diffusion or reinforcement learning.
- real-world datasets for the evaluation in your paper.

## Getting the Raw Datasets

Per agreement with the dataset providers, we provide this tool, and you can download and directly use
the raw dataset from their respective websites, e.g., [levelX](https://levelxdata.com/).
You can directly run this tool on the downloaded raw dataset to get the CommonRoad scenarios.
